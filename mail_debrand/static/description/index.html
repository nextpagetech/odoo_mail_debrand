Odoo Mail

Mail Debrand

Removes Odoo branding links from outgoing email rendering while keeping the original user-written message body intact.

Overview

Mail Debrand extends Odoo mail rendering to remove links pointing to Odoo branding from outgoing email content. It applies during mail template rendering and when preparing outgoing email bodies.

Key Features

Odoo branding link removal

Detects and removes rendered email anchors that link to odoo.com branding content.

Outgoing mail processing

Applies the cleanup when Odoo prepares outgoing mail bodies for sending.

Template rendering cleanup

Applies the same cleanup to rendered mail template output.

Message body preservation

Keeps the original message body content that users explicitly entered.

How It Works

  1. Install the module.
  2. Odoo renders an email template or prepares an outgoing email body.
  3. The module checks longer email HTML content for anchors that link to odoo.com.
  4. Matching branding links are removed from the rendered output.
  5. User-authored mail body content is preserved during outgoing mail preparation.

Benefits

  • Helps keep outgoing business emails focused on your company communication.
  • Works automatically after installation without adding menus or configuration screens.
  • Preserves message content that users intentionally wrote in emails.
